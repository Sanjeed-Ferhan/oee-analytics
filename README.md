# OEE Analytics

Common platform (landing page + analytics) linking all Akij Resource OEE dashboards.

## Pages
- `index.html` — dashboards (cards)
- `analytics.html` — cross-SBU problem finder: last day & MTD OEE, top issues / where to work, and a focus on **Unavailable Order / No Sales Order** losses.

## Dashboards
- ACCL VRM, AIL SMS, AEL Flour, APFIL Loom, APFIL Tapeline, MRML Hulling, MRML Sorting, Akij Feed, AEL Mustard Processing, AEL Mustard Packaging, FAL Hulling, FAL Sorting

All data is pulled live from each SBU Google Sheet on open (last completed day + MTD).
